
# 🎓 CampusVibe – Campus Event Discovery Platform

CampusVibe is a responsive campus event discovery and registration website designed to help students explore upcoming college events and register for activities that interest them.

## ✨ Features

- Explore upcoming campus events.
- Search events by name or description.
- Filter events by category.
- View detailed event information.
- Event countdown timer.
- Student event registration form.
- Form validation for student details.
- Registration confirmation message.
- Save registrations using browser Local Storage.
- Dark and light mode.
- Responsive design for mobile, tablet and desktop.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Interactive functionality.
- Local Storage – Saving registration details in the browser.
- Google Fonts – Typography.

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the CampusVibe folder in Visual Studio Code.
3. Open index.html in a browser.
4. Alternatively, use the Live Server extension in VS Code.

## 💾 Data Storage

The project uses browser Local Storage to store student registration details and theme preferences.

Registration information is stored locally in the user's browser. It is not sent to a central database.

## 🎯 Project Objective

The main objective of CampusVibe is to provide students with a simple and convenient platform to discover campus activities, participate in college events and connect with their campus community.
